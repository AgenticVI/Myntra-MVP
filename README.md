# Myntra Wishlist Conversion MVP

Interactive prototype for the Myntra Wishlist Conversion flow.

## 🚀 Live Demo & Sharable Link
**[https://agenticvi.github.io/Myntra-MVP/](https://agenticvi.github.io/Myntra-MVP/)**

---

## 📱 Features & Highlights
- **Interactive Wishlist Experience**: Realistic browsing, product cards, dynamic wishlist triggers, and urgency indicators.
- **Conversion Flow**: Auto-archive warnings, discount prompts, and quick-add to bag actions.
- **Self-Contained Single-Page Application**: Bundled with React & modern styling, running entirely client-side without external backend dependencies.

---

## 🛠️ Running Locally
You can view the MVP locally in any web browser:

```bash
# Option 1: Python
python -m http.server 8000

# Option 2: Node (npx)
npx serve
```
Then open `http://localhost:8000` in your browser.
